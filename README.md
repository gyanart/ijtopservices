# IJ Top Services — website demo

Static, responsive website demo for a refrigerator and appliance repair provider.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example `ij-top-services-demo`).
2. Upload `index.html` and the entire `assets/` folder to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then **Save**.
5. Once deployed, visit `https://YOUR-USERNAME.github.io/ij-top-services-demo/`.

## Before handing over
- Confirm the business name, phone/WhatsApp number, coverage, and claims with the owner.
- Demo repair images are illustrative, not evidence of actual work.
- The site also uses remote Google Fonts and Unsplash photos in other sections; those need an internet connection.
- GitHub Pages hosts the site, but does not provide a backend booking system.
